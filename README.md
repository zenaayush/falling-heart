# Particle Heart

Blue glowing particles fall from the top of a dark screen and slowly form a beating heart in the center. Fully responsive.

Built with plain HTML, CSS and JavaScript. No libraries needed.

## Run

Open `particles-form-heart.html` in any browser.

## Customize

Everything is in the one file.

- **Particle color:** `blueShades` array (base color is `#4d5dfa`)
- **Background:** `background` in the CSS
- **Number of particles:** `particleArea` in `settings` (smaller = more)
- **Time to form the heart:** `formationSeconds` in `settings`
